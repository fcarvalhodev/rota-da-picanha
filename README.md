# Rota da Picanha

Por que a picanha custa o que custa: IPCA por governo, ciclo do boi, dólar, exportação e China, o que o governo controla, quanto trabalho custa um quilo e quem produz a comida do país. Cada item traz a fonte.

Parte da série [Rotas](https://fcarvalhodev.github.io/rotas/).

Site estático, sem build. Publicado pelo GitHub Pages a partir da branch `main`.
